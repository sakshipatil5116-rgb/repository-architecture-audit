# Semantic HTML5 & Accessible Component Architecture

This repository implements the third task requirements:
- Accessible multi-page layout with header, navigation, sidebar, main content, sections, articles and footer.
- Semantic HTML5 elements.
- Accessible form controls with labels, fieldsets, ARIA descriptions and HTML validation.
- Accessible native dialog modal.
- Keyboard focus indicators and skip link.
- Accessible data table.

## Pages
- index.html
- dashboard.html
- form.html

## Validation
Validate each HTML page using the W3C Nu HTML Checker:
https://validator.w3.org/nu/

The project is designed for zero HTML syntax errors.
